CTE - Common table expression

Conjunto de resultados temporários com nome (tabela virtual) que pode ser utilizado várias vezes dentro de uma consulta para simplificar e organizar queries complexas.

Os [rasura] CTEs são desenvolvidos top-down enquanto as subqueries são desenvolvidas bottom [rasura] up.

Porquê usar CTE?

Eliminamos a redundância das subqueries.

Melhora readability e [rasura] introduz a [modularidade?] e os CTEs são reutilizáveis.

[Pode haver recursivo?]

Na execução da CTE, o db coloca os resultados na cache, executa a query principal buscando os dados do CTE [nos detalhes?], o resultado vai para o db engine e depois volta para o cliente.
